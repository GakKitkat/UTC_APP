## 2026-07-19 - Screen reader accessibility on decorative SVGs\n**Learning:** Decorative SVG icons mixed with text links (like in this app's welcome page) can create a lot of noise for screen readers if not explicitly hidden, degrading the UX for visually impaired users. Main brand logos also need explicit labels.\n**Action:** Always add `aria-hidden="true"` to decorative SVGs accompanying text, and explicitly label meaningful SVGs (like the main brand logo) with `role="img"` and `aria-label`.
